Udyam Setu — solution architecture

The model talks, the rule engine decides, the registries confirm. Prototype: Next.js/HTML PWA + WhatsApp Cloud API front ends, FastAPI services, SQLite/Postgres, a hosted LLM behind a guardrail layer, Bhashini-class ASR/TTS. All data in India.

CHANNELS
WhatsApp BusinessCloud API · text + voice notes · rich quote cards · tracker updates
Web / PWAWorks on a ₹8k phone; session continues from WhatsApp via link
Voice line (IVR)ASR + TTS in 10 languages; call-back when confidence is low
Partner & sales appAssist queue, pre-filled quote, install slot, commission view
API gatewayOTP auth, rate limits, consent token checked on every call
EXPERIENCE SERVICES
Saathi advisor serviceLLM orchestrator with retrieval over catalogue + FAQs. Outputs a structured needs profile, never a price. Guardrails: no product outside the catalogue, no promise outside policy, PII redacted before the model sees text. Works without the LLM (deterministic question flow).
Bundle rule engineDeterministic: city tier, min employees/sites, requires_gstin, requires_one_of, price bands, install days. Returns eligible products + the reasons the advisor turns into plain language.
Quote & checkoutLive price with toggles, setup fees, contract; UPI autopay mandate; one-tap accept; shareable quote
Language layerBhashini / Indic ASR-TTS; translation memory of reviewed phrases per language
Propensity scorerLogistic model on lead profile (AUC 0.71); routes stalled leads to partners
VERIFICATION & ORDER
KYC serviceCapture quality (blur/skew) → OCR → look-alike repair tested against the GSTIN checksum → registry match → name/address/signatory checks → decision with reasons
Registry adaptersGSTIN lookup (status, legal name, address), Udyam lookup. Mocked from the CSVs in the prototype; GSTN / Udyam APIs in production
DigiLocker + e-signFetch GST/Udyam certificates with consent; Aadhaar e-sign of the CAF returns a signed hash only
Order orchestrationProvisioning, SIM dispatch, engineer slotting, failover-first install option
Tracker & notifierEvent-driven status; WhatsApp + SMS templates; owner picks the slot; withdraw consent from the same page
DATA, TRUST & OPS
India region
Customer & order storePostgres, field-level encryption
Document vaultObject store, 30-day TTL (7 days if rejected), every access logged with a reason
Consent ledgerAppend-only: purpose, timestamp, notice version, language, withdrawal
Audit & maskingMasked identifiers in every log and UI; alerts on bulk reads
Analytics & back officeFunnel, leak reasons, partner performance, model evaluation set
Main flow: owner → channel → Saathi (needs profile) → rule engine (eligible bundle) → quote → consent → KYC (lookup first, documents only if needed) → e-sign → order → tracker.
Side flows: stalled or high-value leads → propensity scorer → partner app · every PII touch → consent ledger + masked audit · installation events → WhatsApp notifier.
